WLAN Live Path Tester KO

1. ZIP 파일을 먼저 완전히 압축 해제하십시오.
2. WlanLivePathTester.exe를 실행하십시오.
3. Python 또는 별도 .NET 설치와 관리자 권한은 필요하지 않습니다.
4. 프로그램 시작만으로 외부 측정 요청을 만들지 않습니다.
5. 먼저 '인터페이스 환경', 'WLAN NIC 대응', '어댑터 진단'에서 실제 물리 Wi-Fi와 VPN·가상 NIC 혼재를 확인하십시오.
6. 내부 URL은 DIRECT, 외부 URL은 회사 PROXY 경로인지 확인한 뒤 승인된 대상만 측정하십시오.
7. 브라우저 관찰은 시작 시 물리 Wi-Fi 카운터 ID를 고정합니다. 다른 NIC로 바뀌면 전용 상태로 중단합니다.
8. 실제 회사 환경 검증 방법은 docs\RELEASE_VALIDATION.md를 확인하십시오.
9. 회사 밖으로 보고서를 공유하기 전에 마스킹 내용을 직접 재검토하십시오.
