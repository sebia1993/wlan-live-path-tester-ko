# Windows 수동 검증 매트릭스

| 구분 | 조건 | 기대 결과 |
|---|---|---|
| OS | Windows 11 x64 | 앱 시작 및 로컬 상태 확인 |
| 런타임 | .NET 미설치 PC | self-contained 배포 실행 |
| WLAN | 연결됨 | SSID/BSSID/RSSI/PHY 표시 |
| WLAN | 미연결 | 오류가 아닌 `미연결` 표시 |
| 프록시 | 수동 프록시 | 주소 마스킹 및 사용 상태 표시 |
| 프록시 | PAC | URL별 경로 판정 |
| 프록시 | WPAD | 제한 시간 내 판정 또는 명확한 실패 |
| 인증 | Negotiate | 현재 Windows 사용자 자격 증명으로 성공 |
| 인증 | NTLM | 연결 유지 상태에서 성공 |
| 인증 | 반복 407 | 재시도 상한 후 중단 |
| 내부 URL | DIRECT | 내부망 측정 인정 |
| 내부 URL | 프록시 경유 | 내부망 기준 측정으로 인정하지 않음 |
| 외부 URL | 프록시 경유 | 외부 체감 다운로드 결과 |
| 외부 URL | 403/429 | 속도 장애가 아닌 사이트 정책 오류 |
| 리다이렉트 | 사설 IP로 이동 | 외부 모드에서 차단 |
| EDR/GPO | 일반 사용자 권한 | 관리자 권한 없이 실행 |
