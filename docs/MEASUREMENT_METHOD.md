# 측정 방법

## WLAN 링크

WLAN 링크 속도는 단말과 AP가 협상한 PHY Rx/Tx 속도입니다. 실제 애플리케이션 처리량이 아니며 내부·외부 다운로드 실측과 분리해 표시합니다.

## 내부망 다운로드

무선 단말에서 승인된 사내 유선 서버의 고정 파일을 다운로드합니다. 결과에는 WLAN, AP, 컨트롤러/터널, 사내 유선망, 내부 서버의 영향을 포함합니다.

## 외부망 다운로드

승인된 외부 사이트의 정적 파일을 현재 Windows 사용자 프록시 경로를 통해 다운로드합니다. 결과에는 WLAN, 사내망, 회사 프록시, 인터넷 경계, 외부 사이트 또는 CDN의 영향을 포함합니다.

## 측정 지표

- 실제 수신 바이트
- 총 시간
- 평균 Mbps
- 0.5~1초 구간 Mbps
- TTFB
- HTTP 상태
- 최종 URL과 리다이렉트 횟수
- 프록시 사용 여부와 결정 방식
- 캐시 관련 응답 헤더
- 측정 중 RSSI, BSSID, PHY 변화

DNS·TCP·TLS 세부 시간은 WinHTTP에서 신뢰성 있게 얻을 수 있는 범위와 별도 보조 측정의 차이를 문서화한 뒤 제공해야 합니다.

## 해석 제한

- 프록시 서버 내부 CPU, 세션, 큐, 정책 상태는 확인할 수 없습니다.
- 캐시 적중이면 외부 원본 서버까지의 성능을 반영하지 않을 수 있습니다.
- 한 사이트의 낮은 속도만으로 인터넷 회선 장애를 판정하지 않습니다.
- 내부 서버 또는 외부 사이트 자체가 병목일 수 있습니다.
