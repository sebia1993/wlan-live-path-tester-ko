# 프록시 환경의 제한

## 확인 가능한 것

- 현재 사용자에게 설정된 자동 감지 여부
- PAC URL 존재 여부
- 수동 프록시 존재 여부
- 대상 URL별 예상 `PROXY` 또는 `DIRECT`
- HTTP 407 발생 여부
- 지원되는 인증 방식
- 외부 다운로드의 최종 성공·실패와 체감 처리량

## 확인할 수 없는 것

프록시 관리 권한과 로그 접근이 없으므로 다음은 확인할 수 없습니다.

- 프록시 CPU·메모리
- 전체 동시 세션과 큐
- 정책 엔진 처리시간
- SSL 검사 장비 내부 상태
- 캐시 저장소 상태
- 특정 사용자 정책의 서버 측 상세 로그
- 프록시와 인터넷 회선 사이의 정확한 병목 위치

## 보고서 문구 원칙

잘못된 표현:

> 프록시 서버 장애입니다.

허용되는 표현:

> 내부망 성능은 정상이나 복수 외부 대상의 다운로드 성능이 동시에 낮습니다. 공통 경로인 회사 프록시, 인터넷 경계 또는 외부망 구간의 영향 가능성이 있습니다. 프록시 서버 내부 상태는 접근 권한이 없어 확인하지 못했습니다.
