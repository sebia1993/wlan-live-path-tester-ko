# ADR 0006: URL별 프록시 판정의 fallback 순서

- 상태: 승인
- 날짜: 2026-09-04

## 결정

현재 사용자 설정에 자동 감지와 명시적 PAC가 함께 존재할 때 다음 순서로 별도 판정을 수행합니다.

1. WPAD 자동 검색
2. 복구 가능한 실패일 때 명시적 PAC URL
3. 다시 복구 가능한 실패일 때 수동 프록시와 바이패스 목록
4. 어느 단계도 안전하게 판정하지 못하면 `판단 불가`

PAC/WPAD 취득 중 `ERROR_WINHTTP_LOGIN_FAILURE`가 발생했을 때만 Windows 자동 로그온을 한 번 재시도합니다.

## 이유

- 실제 결과를 만든 설정 출처를 구분할 수 있습니다.
- 자동 판정 실패를 임의 DIRECT로 바꿔 회사 프록시를 우회하는 결과를 피합니다.
- 수동 fallback은 Windows 사용자 설정에 실제로 존재하는 경우에만 사용합니다.
- 처음부터 자동 로그온을 항상 사용하지 않아 자격 증명 전달 범위를 제한합니다.

## 결과

프록시 주소, PAC URL과 바이패스 원문은 public 결과와 기본 화면에 노출하지 않습니다. 실제 HTTP 요청의 407 인증은 별도 구현으로 남깁니다.
