# 무선 중심 안내형 진단 개발

## alpha.12 적용 사항

증상 선택과 저장 전 결과 요약을 제공합니다. IP·게이트웨이·DNS 점검은 로컬 설정 확인이며 도달성 검사가 아닙니다. 공개 릴리스 첨부는 ZIP 하나이며 문서와 라이선스는 내부에 포함합니다. 게시 후 ZIP 바이트와 GitHub SHA-256 digest를 비교합니다. CI의 기존 내부 패키지 호환성 검사 산출물은 공개 첨부와 구분합니다.

## 목적과 완료 기준

초급 무선 네트워크 엔지니어가 개별 기능 메뉴를 먼저 배우지 않고 무선 연결 → 실제 경로 → 서비스 연결 → 성능 비교 → 결과·다음 점검 순서로 진행하도록 한다. 유선·VPN은 실제 경로와 선택적 비교 기준으로 표시한다.

- [x] 다섯 단계 기본 화면, 단계별 질문·해석 제한, 전체 도구 고급 보기
- [x] 기존 수집·측정·프록시 동의·승인 대상·보고서·중지/종료 수명을 유지
- [x] 결과의 근거·의미·다음 점검을 통합하고 미실행/판단 불가를 정상과 구분
- [x] 브라우저 관찰 중 RSSI/BSSID/PHY 변화와 처리량을 함께 해석할 수 있는 표현
- [x] 유선·VPN 동시 활성과 대상 경로의 한계를 명시하고 유선 비교 사용 흐름 제공
- [x] Windows 회귀 및 실제 WPF 레이아웃 렌더링 검증
- [x] 안내서와 릴리스 노트의 패키지 포함 및 누락 검사

공개 배포와 게시 후 검증은 아래 배포 게이트로 별도 확인한다.

## 현재 변경

기존 TabControl의 실행 소유권과 기능 객체를 재사용하며 탭 목록 대신 다섯 단계 탐색을 제공한다. 무선 연결 단계는 WLAN 정보를, 서비스 연결 단계는 프록시 정보를 표시한다. 성능 단계에서 단일/반복/브라우저 관찰을 선택한다. 경로 단계는 인터페이스와 내부·프록시 경로 비교를 연결한다. 이동만으로 수집·DNS·PAC/WPAD·HTTP를 시작하지 않는다. 진행 중에는 단계 변경을 거부하고 실제 작업 완료를 기다린다.

## 범위와 해석

OSI 7계층 전체의 정상 여부를 자동 판정하지 않는다. TLS를 특정 계층 하나에 고정하지 않는다. PHY 속도는 실제 처리량이 아니며 OS 경로 선택은 패킷 경로 전체 증명이 아니다. 브라우저 관찰은 Wi-Fi 전체 카운터이므로 다른 프로그램의 트래픽이 섞인다. AP/프록시 내부 상태·실제 회사 PAC/EDR·드라이버·로밍·절전은 회사 Windows 11 장비에서 별도 검증해야 한다.

## 검증 기록

초기 화면 head `aad4dfe`의 Windows `34099104464`, Guide `34099104459`, Package `34099104456`가 성공했다. 실제 WPF 렌더링 PNG를 두 너비로 수집했다. RenderTargetBitmap이 Window 배경을 포함하지 않는 점을 반영해 루트 Grid에도 동일한 배경을 지정했다.

결과 요약과 관찰 PHY 표시를 포함한 `70be17f5c962499334a69a890a8acb3cb63575da`의 Windows `34099845395`, Guide `34099845461`, Report `34099845558`, Package `34099845388`가 성공했다. 전체 13/13 프로젝트와 중앙 UI 33개 그룹이 통과했다. 글자 누락 의심은 원본 PNG 재다운로드 및 픽셀 비교로 이미지 판독 오류임을 확인했으며 제품 결함으로 기록하지 않는다.

## 유선 비교

기본 제품은 무선 진단이다. 유선은 인터페이스 환경/대상별 OS 경로에서 표시한다. 성능 단계의 '유선과 비교하는 방법'에서 Wi-Fi 측정·보고서 저장 → 유선 연결 및 경로 확인 → 동일 대상·조건 측정 → 시각·서버·캐시·VPN 조건 대조 순서를 안내한다. 자동 어댑터 비활성화나 강제 라우팅은 하지 않는다. 누적 보고서의 측정 시각을 구분하며 직접 경로 검증 없이 Wi-Fi/유선 처리량으로 이름 붙이지 않는다.

## 관찰과 결과

브라우저 관찰의 동일 표본 시각에 수신 처리량·RSSI·BSSID 변경·PHY Rx/Tx를 표시한다. 이 모드는 브라우저 외 트래픽이 섞이며, 프로그램 다운로드 실행과 동시 관찰을 시작하지 않는다. 프로그램 다운로드의 처리량 시계열에 동시 WLAN 측정값이 있는 것처럼 표현하지 않는다.

통합 보고서 저장 성공 화면에서 단계별 자료 유무와 근거·의미·한계·다음 점검을 보여준다. 미실행·실패·부분 성공·차단·경로 불일치를 구분한다. 보고서 생성 시점 WLAN은 과거 다운로드 시점의 무선 상태와 다를 수 있다.

## 배포 게이트

예정 버전은 `v0.1.0-alpha.11`이다. 이 문서는 게시 전 빌드에 포함된다. 공개 여부는 해당 GitHub Release와 Manual Prerelease 실행 결과로 확인한다. 최종 완료 보고 전에 공개 자산 네 개를 다시 다운로드하여 SHA-256, ZIP CRC, 필수 안내서, BUILD_INFO와 태그 소스 SHA 일치를 확인한다. CI용 임시 패키지 성공을 공개 배포 완료로 대체하지 않는다.
