# Windows 릴리스 수동 검증

## 목적

자동 검사는 빌드, 합성 HTTP/프록시, 로컬 보고서, 패키지 구조와 보안 경계를 확인합니다. 실제 Windows 11 무선 어댑터, 회사 고정 프록시·PAC·WPAD, Negotiate/NTLM, GPO·EDR와 Aruba WLAN 동작은 실제 사내 PC에서 사용자가 검증합니다.

실제 주소, SSID, BSSID, 사번, 로그 원문과 보고서는 공개 저장소나 Issue에 올리지 않습니다.

## 배포물

GitHub Release에는 다음 네 파일만 게시합니다.

```text
WlanLivePathTester-win-x64-portable.zip
WlanLivePathTester-win-x64-single-file.exe
SHA256SUMS.txt
THIRD_PARTY_NOTICES.md
```

두 실행 형태 모두 Windows x64 self-contained 빌드입니다. Python, 별도 .NET 런타임과 관리자 권한이 필요하지 않습니다.

- **Portable ZIP:** 호환성을 우선하는 기본 권장 형태입니다. 완전히 압축 해제한 뒤 `WlanLivePathTester.exe`를 실행합니다.
- **단일 EXE:** 복사와 실행이 간단하지만 네이티브 구성요소를 임시 위치에 풀 수 있어 일부 EDR 환경에서는 차단되거나 시작이 느릴 수 있습니다.

## SHA-256 확인

```powershell
Get-FileHash .\WlanLivePathTester-win-x64-portable.zip -Algorithm SHA256
Get-FileHash .\WlanLivePathTester-win-x64-single-file.exe -Algorithm SHA256
Get-FileHash .\THIRD_PARTY_NOTICES.md -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

해시가 다르면 실행하지 않고 파일을 다시 내려받습니다.

## 서명과 SmartScreen

현재 개발 단계 배포물은 상용 Authenticode 인증서로 서명하지 않습니다. Windows SmartScreen 또는 회사 EDR이 `알 수 없는 게시자`로 표시할 수 있습니다.

- GitHub Release 출처와 SHA-256을 먼저 확인합니다.
- 회사 앱 제어 정책을 우회하거나 보안 제품을 비활성화하지 않습니다.
- 차단되면 릴리스 태그와 비식별화한 오류 코드만 기록하고 회사 절차를 따릅니다.

## 기본 실행

- [ ] Windows 11 x64 표준 사용자 권한에서 실행된다.
- [ ] Python·별도 .NET 설치 없이 메인 창이 열린다.
- [ ] 관리자 권한 상승을 요구하지 않는다.
- [ ] 앱 시작만으로 외부 다운로드 측정이 실행되지 않는다.
- [ ] 종료 후 서비스·예약 작업·자동 시작 항목이 생성되지 않는다.
- [ ] 자동 업데이트와 온라인 버전 확인이 없다.
- [ ] Portable ZIP과 단일 EXE 중 적어도 Portable ZIP이 회사 정책에서 실행된다.

## WLAN 상태

`현재 WLAN 확인`을 실행합니다.

- [ ] 실제 무선 어댑터가 선택된다.
- [ ] SSID·BSSID가 현재 연결과 일치한다.
- [ ] RSSI·신호 품질·밴드·채널이 표시된다.
- [ ] PHY, Rx/Tx 링크 속도, 인증·암호화가 표시된다.
- [ ] 무선 연결 해제 시 성공으로 오표기하지 않는다.
- [ ] WlanSvc 중지나 권한 제한은 별도 오류와 조치 문구로 표시된다.

## Windows 프록시와 URL별 경로

`로컬 프록시 설정 확인` 후 승인된 URL로 `이 URL의 프록시 경로 확인`을 실행합니다.

- [ ] 고정 프록시·PAC·WPAD·DIRECT 범주가 현재 사용자 설정과 맞는다.
- [ ] 로컬 설정 확인만으로 PAC 파일이나 대상 URL에 접속하지 않는다.
- [ ] 내부 대상은 기대한 DIRECT 또는 바이패스로 판정된다.
- [ ] 외부 대상은 기대한 PROXY로 판정된다.
- [ ] PAC/WPAD 실패를 임의 DIRECT로 바꾸지 않고 `판단 불가`로 표시한다.
- [ ] 실제 프록시 주소·PAC URL·바이패스 원문을 화면과 보고서에 노출하지 않는다.

URL별 경로 확인은 사용자가 실행하면 PAC/WPAD 및 관련 DNS 통신이 발생할 수 있습니다.

## HTTP 407 통합 인증

- [ ] Negotiate를 NTLM보다 우선한다.
- [ ] NTLM만 제공될 때 현재 Windows 사용자 컨텍스트로 제한적으로 시도한다.
- [ ] 사용자명·비밀번호 입력 또는 저장 기능이 없다.
- [ ] Basic·Digest·Passport 전용 프록시에 현재 사용자 자격 증명을 전송하지 않는다.
- [ ] 반복 407을 무한 재시도하지 않는다.
- [ ] 401 원본 사이트 인증과 407 프록시 인증을 구분한다.
- [ ] Proxy-Authorization 원문이 화면·로그·보고서에 남지 않는다.

## 내부망 다운로드

승인된 사내 HTTP/HTTPS 고정 파일을 사용합니다.

- [ ] DIRECT 또는 명시적 바이패스일 때만 내부망 기준 측정을 시작한다.
- [ ] 프록시 경유로 판정되면 순수 내부망 결과로 사용하지 않는다.
- [ ] HEAD 사전검사, GET 수신량 상한, 시간 제한과 취소가 동작한다.
- [ ] 다운로드 본문 파일을 디스크에 저장하지 않는다.
- [ ] 수신 바이트, 평균 Mbps, TTFB와 소요시간이 표시된다.
- [ ] 외부 또는 허용하지 않은 리다이렉트로 이동하지 않는다.

## 외부망 다운로드

승인된 성격이 다른 외부 대상 2개 이상을 권장합니다.

- [ ] 현재 사용자 프록시 경로를 적용한다.
- [ ] 1~4개 스트림과 전체 수신량 상한이 동작한다.
- [ ] HTTPS에서 HTTP로 내려가는 리다이렉트를 차단한다.
- [ ] 사설·루프백·링크 로컬·예약 주소로 이동하면 차단한다.
- [ ] 401·403·407·429와 시간초과를 낮은 Mbps 성공으로 계산하지 않는다.
- [ ] 캐시 관련 응답 헤더가 있으면 캐시 가능성을 표시한다.
- [ ] 외부 POST·PUT·PATCH·DELETE와 업로드 시험이 없다.

외부 결과는 회사 프록시를 포함한 전체 외부 서비스 체감 다운로드 속도입니다.

## 브라우저 다운로드 관찰

- [ ] 시작 전 3초 백그라운드 기준 수집이 표시된다.
- [ ] 실제 관찰 단계에서 Edge 또는 Chrome 다운로드를 시작할 수 있다.
- [ ] 프로그램 자체 외부 다운로드 요청이 없다.
- [ ] Wi-Fi 수신 Mbps와 기준치 제외 평균·최고값이 표시된다.
- [ ] RSSI, BSSID 변경과 PHY 링크 속도가 같은 시간축에 기록된다.
- [ ] 정지·급락 이벤트와 신뢰도가 표시된다.
- [ ] 유선·VPN·가상 어댑터가 있어도 실제 Wi-Fi 인터페이스를 선택한다.
- [ ] 결과를 브라우저 프로세스 단독 속도로 표기하지 않는다.

## 로컬 보고서

측정 또는 관찰이 끝난 뒤 `로컬 보고서 생성`을 실행합니다.

- [ ] 문서 폴더 아래에 JSON·CSV·HTML·SHA-256 파일이 생성된다.
- [ ] 기존 파일을 덮어쓰지 않는다.
- [ ] HTML이 외부 인터넷 없이 열리며 외부 스크립트·폰트·이미지·iframe이 없다.
- [ ] CSV가 Windows Excel에서 한글로 열린다.
- [ ] SSID, BSSID, IP, MAC, 이메일, 사용자 경로와 URL 호스트·쿼리가 마스킹된다.
- [ ] 실제 프록시 주소, PAC URL과 바이패스 원문이 없다.
- [ ] SHA-256 재계산 결과가 목록과 일치한다.
- [ ] Finding에 근거, 제한된 해석, 한계와 다음 확인 단계가 있다.

자동 마스킹은 보조 수단입니다. 회사 밖으로 공유하기 전 JSON·CSV·HTML을 직접 다시 확인합니다.

## 통신 경계 선택 검증

회사 정책상 허용되는 도구로 확인할 수 있다면 다음 기대값을 사용합니다.

- 앱 시작·WLAN 확인·로컬 프록시 설정 확인·보고서 생성: 외부 측정 요청 없음
- URL별 PAC/WPAD 경로 확인: 사용자 실행 시 PAC/WPAD 및 관련 DNS 가능
- 내부·외부 측정: 사용자가 승인한 대상에 대한 HEAD/GET만 발생
- 브라우저 관찰: 프로그램 자체 외부 요청 없음
- 텔레메트리·자동 업데이트·공인 IP/ISP/GeoIP 조회·결과 업로드 없음
