# WLAN Live Path Tester KO v0.1.0-alpha.11

Windows 11 x64용 무선 중심 안내형 진단 사전 릴리스입니다.

- 여러 기능 탭을 무선 연결·실제 경로·서비스 연결·성능 비교·결과의 다섯 단계로 정리했습니다.
- 기존 개별 도구는 고급 선택에 유지합니다. 단계 이동은 네트워크 측정을 자동 실행하지 않습니다.
- 무선 연결과 프록시 화면을 기본 흐름에서 분리하고 유선·VPN 경로 확인과 수동 유선 비교 순서를 안내합니다.
- 보고서 저장 결과에 자료 유무와 근거·의미·한계·다음 점검을 표시합니다. 미실행은 정상으로 판정하지 않습니다.
- 브라우저 관찰의 같은 표본에 수신량·RSSI·BSSID 변경·PHY Rx/Tx·시각을 표시합니다. 이는 Wi-Fi 전체 트래픽이며 프로그램 다운로드와 별도 모드입니다.
- 이전 공개본 이후의 입력 경계·중앙 실행/종료·경로 보고서 변경을 포함합니다.

배포물은 Portable ZIP, single-file EXE, SHA256SUMS.txt, THIRD_PARTY_NOTICES.md 네 개입니다. Portable ZIP에 새 진단 안내서를 포함합니다.

이 버전은 코드 서명되지 않았습니다. 실제 회사 PAC/WPAD·407·TLS 검사·VPN·EDR·로밍·절전 검증은 별도입니다. OSI 전체 정상 여부, AP·프록시 내부 장애를 확정하지 않습니다. 동기 WinHTTP 호출은 중지 즉시 반환하지 않을 수 있습니다. 일부 기존 보고서 writer의 파일세트 rollback은 미지원입니다.
