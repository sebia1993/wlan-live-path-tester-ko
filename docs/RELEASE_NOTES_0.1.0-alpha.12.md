# v0.1.0-alpha.12 — 증상 중심 초급 진단

- 시작 화면에서 연결 안 됨 / 인터넷 안 됨 / 느림 / 자주 끊김을 선택하고 필요한 단계로 이동합니다. 증상 선택만으로 수집이나 외부 요청을 실행하지 않습니다.
- IP·게이트웨이·DNS 로컬 설정 점검을 추가했습니다. 링크 비활성, 링크 로컬 주소만 있음, 설정 읽기 실패를 구분하며 DHCP 장애나 통신 성공으로 단정하지 않습니다.
- 서비스 단계 이름과 안내를 실제 프록시 확인 범위에 맞췄습니다. DNS·TCP·TLS 개별 검사는 미검사로 표시하고 실제 HTTP 확인은 승인 대상 측정으로 연결합니다.
- 승인 대상 JSON을 파일 선택으로 불러오고, 잘못된 파일은 기존 입력과 승인 모드를 유지합니다. 고급 측정 설정은 기본으로 접습니다.
- 결과 화면에서 저장 전에도 기본 설정과 최근 내부/외부 HTTP 측정, 미확인 항목, 다음 행동을 확인할 수 있습니다.
- 공개 릴리스 첨부는 WlanLivePathTester-win-x64-portable.zip 하나입니다. 압축을 모두 해제하고 WlanLivePathTester.exe를 실행하세요. 라이선스·제3자 고지·사용 안내는 ZIP 안에 포함됩니다. GitHub 자동 Source code 항목은 별도입니다.

## 범위와 검증

실제 무선망·AP/WLC·RADIUS·회사 PAC/VPN/EDR/GPO 및 키보드/스크린리더 검증은 별도입니다. IP 설정 존재는 도달 가능성의 증거가 아닙니다. 유선 비교는 연결과 시각을 사용자가 관리하는 수동 비교입니다. 공개 전 Windows 자동 테스트·패키지 검증을 수행하며 게시 후 다운로드 바이트와 GitHub SHA-256 digest, ZIP 및 BUILD_INFO를 대조합니다.
