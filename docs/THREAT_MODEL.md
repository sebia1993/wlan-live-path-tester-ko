# 위협 모델

## 보호 자산

- 사내 프록시와 PAC 정보
- 내부 URL과 네트워크 주소
- SSID, BSSID 및 WLAN 상태
- 측정 결과와 장애 시각
- 사용자·컴퓨터 식별정보

## 주요 위협과 대응

| 위협 | 대응 |
|---|---|
| URL이 로컬 관리 인터페이스로 리다이렉트 | 모든 리다이렉트 재검증, 외부 모드의 사설·루프백·링크 로컬 차단 |
| 측정 URL에 자격 증명 포함 | URL userinfo 거부 |
| 결과·로그의 외부 반출 | 외부 업로드 기능 미구현, 로컬 저장만 허용 |
| 자동 업데이트를 통한 공급망 위험 | 런타임 업데이트 기능 금지 |
| 프록시 주소가 보고서로 노출 | 기본 마스킹 |
| 무한 다운로드 또는 대용량 과부하 | 최대 바이트, 시간, 스트림, 리다이렉트 수 강제 |
| 프록시 인증 반복 루프 | 동일 407 반복 상한과 명확한 실패 처리 |
| 네이티브 핸들·메모리 누수 | SafeHandle/finally 및 단위 경계 테스트 |
| 외부 사이트 한 곳의 느림을 회선 장애로 오판 | 복수 외부 대상과 내부망 결과 비교 |
| 프록시 내부 장애로 잘못 단정 | `공통 외부 경로 가능성`까지만 표현 |
