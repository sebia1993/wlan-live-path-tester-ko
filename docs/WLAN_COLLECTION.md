# Native WLAN 상태 수집

## 목적

Windows 명령 출력 언어에 의존하지 않고 `wlanapi.dll`을 통해 현재 무선 연결 상태를 읽습니다. 이 기능은 로컬 운영체제 API만 호출하며 외부 네트워크 연결을 만들지 않습니다.

## 수집 항목

| 항목 | 의미 |
|---|---|
| 인터페이스 설명 | Windows가 제공하는 무선 어댑터 설명 |
| 연결 상태 | 연결됨, 미연결, 인증 중 등 |
| SSID | 현재 연결된 무선 네트워크 식별자 |
| BSSID | 현재 연결된 AP 라디오 MAC 주소 |
| RSSI | 수신 신호 강도 dBm |
| 신호 품질 | Windows가 제공하는 0~100 범위 값 |
| 채널 | Windows 채널 쿼리 또는 중심 주파수 계산값 |
| 중심 주파수 | 현재 BSSID와 BSS 목록을 비교해 얻은 MHz 값 |
| PHY | 802.11a/b/g/n/ac/ax/be 등 연결 PHY 유형 |
| Rx/Tx 링크 속도 | 단말과 AP 사이에서 협상된 PHY 속도 |
| 인증·암호화 | Windows가 제공하는 인증·암호 알고리즘 |

## 중요한 해석 제한

Rx/Tx 링크 속도는 실제 파일 다운로드 처리량이 아닙니다. 무선 오버헤드, 재전송, 채널 점유, 프록시, 서버 및 유선 경로의 영향을 반영하지 않으므로 이후 내부·외부 다운로드 측정값과 분리해 표시합니다.

RSSI, 채널 또는 중심 주파수의 개별 쿼리가 실패해도 현재 연결 정보가 확인되면 전체 조회를 실패시키지 않고 `부분 제한`으로 표시합니다.

## 개인정보와 표시

SSID와 BSSID는 사용자 화면에서 확인할 수 있지만 저장 보고서에서는 기본 마스킹 정책을 적용할 예정입니다. 저장소와 자동 테스트에는 합성 SSID/BSSID만 사용합니다.

## Windows 권한

Windows 11의 버전과 회사 정책에 따라 WLAN 세부 정보 접근에 위치 권한이 필요할 수 있습니다. 접근 거부는 무선 미연결과 구분하며, 위치 권한 또는 GPO 정책을 확인하도록 안내합니다.

## 검증 범위

GitHub Windows CI는 P/Invoke 선언의 컴파일, 자체 점검, publish 가능 여부를 검증합니다. 실제 어댑터의 반환 구조체, 위치 권한, 드라이버별 값은 실제 Windows 11 PC 수동 검증이 필요합니다.
